Introducing AlbionKit Mobile, a companion app for Albion Online players.
Follow the markets, find trading opportunities, and plan your next move with
useful game tools in one place.

## Features

| Feature | What you can do |
| --- | --- |
| Market overview | Browse market opportunities and compare prices across cities. |
| Gold tracker | Follow gold prices and estimate silver-to-gold conversions. |
| Profit calculators | Check returns for cooking, farming, animal breeding, alchemy, labourers, and chopped fish. |
| Faction timing | Check upcoming bandit windows and set local reminders. |
| Server status | See the status of Albion Online’s West, East, and Europe servers. |
| Personal settings | Choose your language, theme, and preferred server region. |

### Install on Android

1. Open the [latest release](https://github.com/cosmic-fi/albionkit/releases/latest)
   on your Android device.
2. Download the file ending in `.apk`.
3. Open the downloaded file and follow Android’s installation prompts. If asked,
   allow your browser or file manager to install apps from this source.

Because the APK is installed outside Google Play, Play Protect may warn that
the app is unrecognized or has not been scanned. Only proceed if you downloaded
the APK from the official release link above and trust its source. If Android
offers **More details** and **Install anyway**, you can choose those options to
continue. Do not bypass a warning if the APK came from another site or Android
reports a specific security threat.

Release assets ending in `.aab` are for Google Play publishing and cannot be
installed directly.

The installed app version and build number appear in **Settings**. Beta
versions, such as `1.0.0-beta`, are shown there with the beta label and are
published as GitHub pre-releases.
