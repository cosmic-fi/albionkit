# Changelog

All notable changes to AlbionKit will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial private build setup
- Translation infrastructure and locale files
- Language persistence and contribution links

### Changed
- Project restructured into private build (`albionkit.com`) and public repo (`ao-pocket`)

## [1.0.0] - 2026-08-25

### Added
- Public release of AlbionKit platform
- Market Flipper with real-time arbitrage across all cities
- Gold Price Tracker with historical charts
- Profit calculators: Farming, Animal Breeding, Cooking, Alchemy, Enchanting, Labourers, Chopped Fish
- PvP Intel: player stats, killboards, ZvZ tracking
- Build database with community builds and weapon rotations
- Guides: Getting Started, Gathering Routes, Silver Farming, Combat Positioning
- Multi-language support (10 languages)
- PWA support with offline caching
- Dark / Light theme support
- Notifications for market alerts and watchlist updates

### Changed
- Migrated from private development to public platform
- Updated branding and public-facing documentation
- Consolidated tooling under the AlbionKit name

### Fixed
- Initial stability and performance improvements for public launch

## [0.1.0] - 2026-01-01

### Added
- Initial beta release with core market and PvP tools
- Profit calculators for crafting, farming, and gathering
- Basic multi-language support
- User authentication and preferences
